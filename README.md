Ce plugin s’intègre au système domotique libre Jeedom (https://www.jeedom.com, https://github.com/jeedom).

Il permet de contrôler les appareils compatibles Home Connect.

Un mode de démonstration utilisant des appareils simulés est également disponible.

Le plugin a été créé à l’origine par Sartog.

Le dépôt GitHub d’origine de Sartog est disponible à l’adresse https://github.com/Sartog/homeconnect.

Pour signaler un problème ou proposer une fonctionnalité, ouvrez une issue sur le dépôt.
